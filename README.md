
# 💰 Python Expense Tracker

A simple Python-based expense tracker to record daily expenses and manage personal spending.

## ✨ Features

- Add and record daily expenses
- View all recorded expenses
- Calculate total spending
- Categorize expenses
- Track spending history

## 🛠️ Technologies Used

- Python 3
- File handling
- Functions and data structures

## 🚀 Getting Started

### Prerequisites

- Python 3 installed on your computer

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/python-expense-tracker.git
   ```

2. Open the project folder:

   ```bash
   cd python-expense-tracker
   ```

3. Run the program:

   ```bash
   python main.py
   ```
